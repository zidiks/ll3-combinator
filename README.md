# Arsenal Designer v2

Веб-тула для проектирования оружия, модулей, модификаторов и **композиционной системы эффектов** для PvPvE-экстракшена с рогалик-драфтом.

## Запуск

```bash
python -m http.server 8765
```

http://localhost:8765. Без сборки и зависимостей. Правки из UI живут в `localStorage`; «Данные → Скачать JSON» экспортирует всё, «Экспорт для Unity» — отдельный JSON для движка.

## Идея системы

Эффекты не пишутся руками парами, а **собираются из примитивов**:

| Слой | Что это | Примеры |
|---|---|---|
| **Нагрузка** (`payloads`) | статус на цели или на себе, с элементом, цветом, VFX-аурой и формами прилагательного | поджог, обморожение, разряд, метка, отбрасывание, кровотечение, казнь, лечение, щит |
| **Доставка** (`deliveries`) | как эффект доходит до целей; существительное с родом; список VFX-примитивов | молния, рикошет, пробитие, осколки, взрыв, зона, воронка, волна, импульс, отражение, фантом, призыв, ловушка, спутники |
| **Носитель** (`weaponKinds`) | базовая доставка оружия | пуля, веер (дробь), стрела (заряд), сюрикен, клинок, замах, блок |
| **Триггер** | когда срабатывает | при попадании / крите / убийстве / блоке / периодически / активация / ульта |

Мод или модуль = список эффектов `{ trigger, delivery?, payload?, inherits?, every?, radius?, targets?, dmg?, condition?, upgrade? }`.

Движок (`computeBuild` в `app.js`):

1. **Базовый канал** оружия несёт все `on_hit`-нагрузки без доставки. Частота = попаданий/с (с учётом магазина, мультиснаряда и «продолжений» снаряда — рикошет/пробитие/осколки умножают попадания).
2. **Вторичные каналы**: каждая доставка мода/модуля. Если `inherits: true` — канал несёт нагрузки базового канала: **поджог + молния = «Огненная молния»**, поджог + обморожение + рикошет = «Огненно-ледяной рикошет». Легендарный «Синтез» включает наследование всем.
3. **Имя** = прилагательное нагрузки в роде существительного доставки (+ ручные переопределения в `compositeOverrides`).
4. **Статусы**: наложений/с по каждому статусу (сумма по каналам × целей).
5. **Реакции** (`reactions`): пара статусов на одной цели → именованный эффект, интенсивность = min(наложений/с).
6. **Вариации оружия** (`weaponVariants`): как та же доставка звучит на дробовике / луке / бите.
7. **VFX-рецепт** канала = примитивы доставки, тонированные цветами элементов, + аура статуса.

### Для Unity

`vfxPrimitives` — библиотека из ~30 примитивов; каждый = один VFX Graph subgraph (`unity`), точка привязки (`attach`) и экспонированные свойства (`ColorA/ColorB/Radius/...`). Любой композит собирается из них в рантайме — новые комбинации не требуют новых ассетов. «Экспорт для Unity» отдаёт: примитивы, нагрузки, доставки, реакции, все композиты (доставка × 1–2 статуса с именами и цветами), оружие, модули, моды.

## Модули оружия

Мета-слой синергии. Слоты: **ядро** (статус на попадание), **излучатель** (доставка), **каркас** (статы). Ставятся до катки, в конструкторе участвуют наравне с модами: наследуются, реагируют, попадают в авто-имена. Слоты открываются тирами оружия.

## Вкладки

- **Конструктор** — библиотека слева (клик добавляет, несовместимые погашены), билд с модулями посередине, справа статусы/реакции/предупреждения; ниже граф «носитель → каналы → статусы → реакции» и карточки каналов с VFX-рецептами.
- **Синергии** — таблица реакций (клик = редактировать/создать), таблица «доставка × статус» с авто-именами (клик = ручное имя), вариации по оружию, «с чем комбинируется мод».
- **Оружие / Модификаторы / Модули / Мета / Данные** — редакторы и словари (нагрузки, доставки, VFX-примитивы, вариации).
