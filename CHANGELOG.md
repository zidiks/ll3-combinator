# Changelog

Формат: дата — что изменилось. Поле `updated` в `data.json` дублирует дату последнего изменения **данных**.

## 2026-09-05 — иконки модификаторов

- У всех 80 модов появилось поле `icon` — своя иконка из бесплатного пака **500 Free Skill Icons** (подобрана под смысл мода: кроссовок на скорость бега, прицел на «Охотника», чёрная дыра на «Коллапс»…).
- Новый блок `iconSet` в `data.json`: шаблоны путей для сайта (`icons/{icon}.webp`) и для Unity (`Assets/500FreeSkillIcons/Icons/{icon}.png`) — потребителю не нужно знать про пак ничего, кроме имени файла.
- `icons/` — 80 файлов WebP 256×256 (~670 КБ на всё), деплоятся вместе с сайтом. Пересборка: `python scripts/icons.py`.
- Иконки показываются в таблице модификаторов, в библиотеке и слотах конструктора, в карточках оффера драфта, в топе кандидатов и в каталоге синергий; `docs/catalog.md` получил колонку «Иконка».
- `scripts/build.mjs` проверяет: у каждого мода есть `icon`, файл существует, дубли и неиспользуемые файлы — предупреждениями. JSON Schema обновлена.
## 2026-09-03 — машиночитаемость

- `data.json` стал единственным источником истины (раньше `data.js` с `window.DEFAULT_DATA`). UI загружает его через `fetch` и стартует `app.js` после.
- Добавлены `docs/mechanics.md` (спецификация правил и формул движка), `schema/data.schema.json` (JSON Schema с описанием полей), `llms.txt`, `robots.txt`, `sitemap.txt`.
- `engine.js`: авто-имена композитов и Unity-экспорт вынесены из `app.js` в общий модуль (браузер + Node).
- `scripts/build.mjs`: валидация `data.json` (ссылочная целостность id, роды, сортировки, слоты) и генерация `unity.json` и `docs/catalog.md`. Запускается Vercel на деплое.
- В `data.json` добавлено поле `updated`. Данные не менялись.

## 2026-09 (ранее, по коммитам)

- Слоты 5/3/1 + слот предмета: предметы с карты (`on_use`), принудительный оффер ульты на 10-м уровне, пики 5/10.
- Профили дальности оружия (min/optimal/max/falloff/штраф в упор), модули дальности, слайдер дистанции в конструкторе.
- Правила драфта: пул по форме оружия, умные веса, превью оффера, пиковые уровни, бан-жетоны; лаборатория = анлоки.
- Arsenal Designer v2: композиционная система эффектов, модули оружия, экспорт VFX для Unity.
